 Apple

조용한 기능 레이어

검색과 내비게이션은 콘텐츠 위에서 방향을 잡아주되 콘텐츠 자체를 압도하지 않습니다. 정렬, 여백, 읽기 순서로 계층을 만듭니다.

적용: 상단 탐색 패널만 가벼운 material, 피드 본문은 단색 surface와 선명한 대비.
Spotify-inspired

콘텐츠가 주인공

일관된 토큰, 강한 단일 액센트, 지속되는 플레이어가 탐색과 재생을 하나의 경험으로 연결합니다.

적용: 보라는 AI 행동, 민트는 재생 상태에만 사용. 기능별 색의 의미를 고정.

Focus Feed
디자인 원칙

새 기능을 추가할 때도 판단 기준이 흔들리지 않도록 네 가지 제품 원칙으로 압축합니다.

01

발견은 한곳에서

검색, 트렌드, 소스 전환을 하나의 탐색 패널에 유지합니다. 상세 필터는 필요할 때만 펼칩니다.

02

콘텐츠는 평평하게

카드 안의 카드를 줄입니다. RSS는 스캔이 빠른 행, YouTube는 썸네일 그리드라는 콘텐츠 특성을 존중합니다.

03

행동 색은 하나씩

AI=보라, 재생=민트, 정보 소스=파랑/빨강. 장식용 그라데이션은 핵심 기능 레이어에만 제한합니다.

제안 화면

데스크톱은 넓은 스캔, 모바일은 엄지 이동과 지속 재생을 우선합니다. 같은 토큰을 쓰되 밀도는 기기에 맞춥니다.
